# İymus Card-Based RPG Poker Game

Terminalde oynanan, C++ ile yazılmış bir poker oyunu. Poker oynayarak düşmanları yen.

## İndirme ve Çalıştırma
1. [Releases](../../releases) sayfasından `iymus_rpg_poker.exe` dosyasını indir.
2. Çift tıklayarak çalıştır. Kurulum veya derleme gerekmez.

## Antivirüs Uyarısı
Bazı antivirüsler yeni ve imzasız exe dosyalarını yanlışlıkla zararlı olarak işaretleyebilir. Bu bir **yanlış pozitiftir**. Kaynak kodun tamamı bu repoda açık, istediğin zaman inceleyebilirsin.
Windows SmartScreen uyarısında "Daha fazla bilgi" → "Yine de çalıştır" seçeneğini kullanabilirsin.

## Nasıl Oynanır
- Düşmanları yenmek için onları haritadan bulup yanlarına git. İstersen savaşabilir veya kaçmaya çalışabilirsin. 
- Savaş esnasında 8 karttan 5 tanesini seçip en iyi kombinasyonu yaparak hasarını katla.
- Elin kötü geldiyse seçtiğin kartı veya kartları değiştirebilirsin.

## Kontroller
- WASD ile hareket edebilirsin.
- P senin karakterin D ise düşmanlar.
- Zaten devamını oyunun içinde öğrenirsin.

## Özellikler
- Terminalde oynanan rpg oyun.
- Tek bölüm 8 düşman.
- Q ile duraklatma menüsünden poker kombinasyonlarını inceleyebilirsin.

## Gereksinimler
- Windows

